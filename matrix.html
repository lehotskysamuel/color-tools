OKLCh Atlas Difference matrix

Difference matrix

How different every pair of paints looks. Each paint is a row and, in the same order, a column, sorted by code. Where two paints meet, J is their distance in just-noticeable differences: their OKLab distance ΔEOK divided by 0.02.

Hover a cell to see both paints and their ΔEOK. The table is symmetric: the row and column of a paint hold the same values. Paints without a code (Kimera Kolors) come last.

J = 1 (ΔEOK 0.02) is about one just-noticeable difference, the threshold CSS Color 4 uses for gamut mapping. Straight-line OKLab distance is a good model for small and medium differences and overstates very large ones.

Each paint sits at the color its maker shows on its website, as in the atlas, so every range is measured from the same kind of data.
